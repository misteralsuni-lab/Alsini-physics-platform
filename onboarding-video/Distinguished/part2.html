Backend Services
FastAPI tutor engine, RAG pipeline, grading, search
Tutor Chat
POST /api/tutor/chat. Retrieves relevant chunks, then streams LLM response with SSE.
LLM Router
Provider-agnostic: openai (GPT-4o), gemini (2.5 Flash), ollama (local), custom. Failover: primary → fallback → local.
Grading Engine
/api/grade. LLM-based free-text grading with rubric. MCQ/multi-select graded deterministically.
Search & Embeddings
/api/search — full-text search. /api/rag/embed-chunk — embeddings via text-embedding-3-small (500-token chunks).
Alsini Physics PlatformBackend Services
Data Layer
Supabase schema, RLS policies, curriculum hierarchy
Curriculum Hierarchy
5-level tree: curriculum → topics → subtopics → lessons → worksheets. UUID PKs, exam_board + level metadata.
Resource & Quiz Tables
resource_assets — PDF images, text blocks, positions. quiz_attempts — per-question results, scores, feedback, indexed on student_id + worksheet_id.
Row-Level Security
RLS on all tables. Students see own quiz attempts. Teachers see assigned students. Admins full access.
Migrations
migrations/*.sql. Curriculum seeding via node scripts/seed_curriculum.js. Checks for existing data.
