System Architecture
Dual-backend, Supabase spine, curriculum-first design
Frontend — React + Vite
SPA on port 5173. Auth via Supabase, role-based routing (admin/student/teacher). Components: VLEDashboard, InteractiveTutor, HybridDocumentViewer, QuizEngine.
Backend — FastAPI (port 8000)
Python 3.11+ with Uvicorn. AI tutor engine with RAG pipeline. Routes: /api/tutor/chat, /api/grade, /api/search.
Supabase — Database & Storage
PostgreSQL with RLS. Curriculum hierarchy: curriculum → topics → subtopics → lessons → worksheets.
Express Server (port 3001)
Legacy Node.js server. Being migrated to FastAPI. Manages PDF uploads and text extraction.

VLE Dashboard
Student-facing dashboard showing topic progress, upcoming deadlines, worksheets and quizzes.
Interactive Tutor
AI-powered chat with streaming responses. Context-aware: receives curriculum chunk IDs, topic metadata, conversation history.
Hybrid Document Viewer
Renders PDFs with overlaid interactive elements. PyMuPDF images as base layer, Supabase text on top.
Quiz Engine
Multi-format quiz: MCQ, multi-select, free-text, calculation. Auto-grades via /api/grade.
Search Panel
Full-text search across curriculum content. Supabase full-text search with ranking.
Auth & Role Routing
Supabase Auth with JWT tokens. Roles: admin, teacher, student. Protected routes.
