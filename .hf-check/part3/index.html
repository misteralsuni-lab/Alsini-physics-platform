Key User Workflows
How students and teachers use the platform
RAG Tutor
Student question → retrieve relevant chunks → context → stream LLM response with citations.
Worksheet Viewer
Open worksheet → PDF images + text overlay → interactive highlight and note elements.
Quiz & Grading
Start quiz → render → submit → auto-grade (MCQ) or LLM-grade (free-text) → store in quiz_attempts.
Search
Full-text search across curriculum → ranked results → click to open source PDF at exact page.
